Chromecast with Google TV 4K 兒童計時系統 · 背景看門狗 ＋ Telegram 家長核准 · 目前版本 v9 A screen-time system for kids on Chromecast with Google TV 4K · watchdog + Telegram parent approvals · current version v9

功能Features

計時規則Timing rules 單次 30／45／60 分或自訂（5–180 分）；每日上限可自訂（預設 120 分）看滿硬停；午夜自動結清。 30/45/60-minute sessions or custom (5–180 min); customizable daily cap (default 120 min), hard stop; sessions close out at midnight.
看門狗監看Watchdog 無障礙＋UsageStats 雙訊號盯前台；離開自動暫停、回來續看剩餘時間。 Accessibility + UsageStats track the foreground app; leaving auto-pauses, remaining time resumes later.
系統強制鎖定System lockdown 小孩狀態下設定與 Play 商店被強制鎖定並週期重申，防止改設定或移除本 App。 In kid mode, Settings and the Play Store are force-locked and re-asserted, blocking tampering or uninstall.
Telegram 核准Telegram approvals 專用 bot 回報開始／結束；爸媽在群組一鍵核准、遠端 +15／+30 分或立即結束。 A dedicated bot reports start/end; either parent approves in a group chat, adds +15/+30 min, or ends the session.
家長模式Parent mode PIN 或 Telegram 核准進入，2 小時或待機自動結束，期間看門狗休眠。 Enter by PIN or Telegram approval; ends after 2 hours or on standby; the watchdog sleeps meanwhile.
清單自訂＋雙語Custom list + bilingual 觀看清單可增減任意已安裝 App；介面繁體中文／English 可切換。 Add or remove any installed app on the watch list; UI switches between Traditional Chinese and English.

運作方式How it works

  • 純 Android framework API、零第三方函式庫；前台服務常駐，狀態全部持久化，重開機自動還原（今日累計具 NTP 校時防護）。 Pure Android framework APIs, zero third-party libraries; a foreground service keeps watch, all state persists and restores across reboots (daily total hardened against NTP sync delay).
  • Bot token 不寫在程式碼裡：家長在 PC 產生 token 檔，經 ADB 推入裝置，App 匯入私有儲存後刪除原檔。 The bot token is never in the source: a parent pushes a token file via ADB; the app imports it into private storage and deletes the file.
  • 沒有時段就開觀看 App 會被全屏攔截，可直接開局或送出核准請求；剩 1 分鐘警告、到時回主畫面鎖定。 Opening a viewing app with no session shows a full-screen gate — start a session or request approval; 1-minute warning, then auto-lock at time-up.

建置與安裝Build & install

  • 一般使用者免編譯：到 Releases 下載最新版 APK，再照 詳細安裝教學 逐步完成（建機器人、取 token、傳入、權限、配對、疑難排解）。 End users: no build needed — download the latest APK from Releases and follow the detailed setup guide (bot, token, import, permissions, pairing, troubleshooting).
  • 以 ADB 側載至 Chromecast with Google TV 4K（Android TV OS 14 實測），授予懸浮窗、無障礙、使用情況存取三項權限，並完成 token 匯入、bot 配對與 PIN 設定。 Sideload via ADB onto a Chromecast with Google TV 4K (tested on Android TV OS 14); grant overlay, accessibility and usage-access permissions, import the token, pair your bot and set a PIN.
  • 開發者從原始碼建置：JDK 21 ＋ Gradle 8.9 ＋ Android SDK 34，執行 gradle assembleRelease。 Developers building from source: JDK 21 + Gradle 8.9 + Android SDK 34, run gradle assembleRelease.

已知限制（誠實揭露）Known limitations

  • 手機投放（Cast）不計時。Casting from a phone is not timed.
  • 看門狗程序若被系統終止，採 fail-open（短暫空窗），非常駐 root 等級強制方案。 If the system kills the watchdog it fails open (a brief gap); this is not a root-level enforcer.
  • 僅針對 Android TV／Google TV 設計；保留原廠首頁與投放。 Designed for Android TV / Google TV only; keeps the stock home screen and casting.
